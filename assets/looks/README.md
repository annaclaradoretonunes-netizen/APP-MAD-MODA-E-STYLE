# Fotografias dos looks

Coloque aqui as 32 fotografias originais dos looks, sem recortar as modelos.

Nomes sugeridos: `look-01.jpg` até `look-32.jpg` (ou `.png`, conforme o formato original). Não renomeie `.png` para `.jpg` sem converter o arquivo.

A inclusão nesta pasta não as exibe automaticamente no aplicativo: cada foto deverá ser vinculada ao look correto no código ou no Supabase.

Antes de publicar fotos de outras pessoas, confirme a autorização de uso.
